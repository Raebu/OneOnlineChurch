Accessibility

We aim for WCAG 2.2 AA. The prototype supports keyboard navigation, visible focus, reduced-motion preferences, semantic landmarks, labelled search controls and a text alternative to the decorative globe.

Formal assistive-technology testing and an independent accessibility review remain outstanding. We do not yet claim WCAG conformance.

Upcoming church listings will disclose accessibility features only when the churches have provided and confirmed them.
